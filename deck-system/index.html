Slide Format Library

ベースフォーマットと、そこから派生した目的別フォーマットを一覧管理するための静的ページです。Cloudflare Pages 等では、このフォルダをそのまま公開対象にできます。

Base Format

Plain Neutral

白背景、薄い罫線、最小限の余白とグリッドだけで構成した汎用ベース。企業別フォーマットを作る前の標準土台です。

 Base Format

Plain Business PPT

業務PPT群の構図をもとにした別系統のプレーン。表紙・間仕切り・図解・表・比較・image2本文版・SVG図解版まで85構図を管理します。

 Company Format

Kikai Business PPT

Plain Business PPTのPB-00からPB-84をKikai企業版として取り込んだ構図カタログ。ロゴ、濃いグレー、タイトル下線、右上ヘッダーを適用済みです。

 Current Reference

Honshitsu AI Course Format

現行の講義スライド用フォーマット。ベースというより、セミナー用途に寄った目的別フォーマットとして参照します。

 Registry

Base Formats

今後追加するベースフォーマットの一覧。プレーン、報告書向け、講義向け、提案書向けなどをここに増やします。

 Registry

Company / Purpose Formats

Plainなどのベースから、企業別、案件別、用途別に派生させたフォーマットパックをここに蓄積します。

 Workflow

Plain to Company Deck

Plain Neutralを親にして企業フォーマットを作成し、台本入力からスライド化するための標準工程です。

 Decks

Generated Decks

台本、スライド計画、企業フォーマットを合成して作成した資料を蓄積します。

運用ルール: ベースフォーマットは背景装飾、ブランド色、ロゴを持たない。企業別・案件別の色、ロゴ、背景、間仕切り、フッター規則は目的別フォーマット側で追加する。
