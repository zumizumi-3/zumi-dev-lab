Company Format / Derived from Plain Neutral

落ち着いた熱量で、つくる力を伝える。

濃いグレーの文字、控えめなオレンジ、余白を広く取った構成で、講座・提案・ワークショップに使える企業フォーマット。

Kikai / Vibe Coding SalonKKV-00
Section
01

まず、何を変えるのかを揃える。

章の切り替えは強い装飾ではなく、番号・短い見出し・余白で静かに区切る。

Three Signals

スライドは、説明量よりも判断しやすさを優先する。

1 結論を先に置く

見出しは話題名ではなく、伝えたい判断や気づきにする。

2 本文は絞る

詳細はスピーカーノートに逃がし、画面上は2から3点に抑える。

3 余白で格を作る

背景装飾ではなく、間と整列でシックな印象をつくる。

伝えること

Before

→
After

Kikai / Vibe Coding SalonKKV-04
Process

Plainから企業フォーマット、台本入力へ進める。

1 Plainを選ぶ

構造と密度だけを親にする。

2 ロゴを入れる

ロゴ、色、余白、区切りを定義する。

3 台本を分解

話す内容をスライド単位にする。

4 合成する

本文、ノート、視覚要件を当てる。

強調 オレンジ 番号、点、細い罫線などに限定する。
背景 暖かい白 大きな塗りや柄は使わない。
