Base Format Plain Neutral

情報を邪魔しない、無地のスライド土台

背景装飾、ブランド色、ロゴを入れず、企業別・案件別フォーマットへ派生しやすい基本構造だけを持つ。

title + lead + generated image PN-26
Text Only Narrative page

すべて文章で表現するページ

図解や画像を使わず、論理の流れだけで読ませる。登壇中に一文ずつ追ってもらう場合や、配布後に読み返される前提の資料に使う。

文章だけのページでは、段落ごとに役割を分ける。最初に結論、次に背景、最後に読み手の判断や行動を置く。

text-only narrative PN-27
Text Only Two-column memo

長めの文章は、2カラムで論点を分ける

左側には、背景、前提、これまでの経緯を書く。読み手が判断する前に必要な文脈をまとめる。

本文は短い段落へ分け、1段落1論点にする。

右側には、示唆、判断、次の行動を書く。背景説明と結論が混ざらないようにする。

画像やカードを使わない代わりに、余白と段落で読み順を作る。
