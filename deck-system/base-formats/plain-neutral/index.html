Base Format Plain Neutral

情報を邪魔しない、無地のスライド土台

背景装飾、ブランド色、ロゴを入れず、企業別・案件別フォーマットへ派生しやすい基本構造だけを持つ。

cover PN-00
Section Divider

章の区切りは、文字と余白だけで見せる

目的別フォーマットでは、この区切りに色、写真、ロゴ、背景帯などを追加できる。

section divider PN-01
Message One slide / one message

見出しは、そのスライドで持ち帰る結論を書く

本文は短く、詳細説明は講師メモや補足資料へ逃がす。文字を小さくして詰め込まない。

1結論

この1枚で伝える判断を固定する。

2理由

本文は2から3点までに抑える。

3次の行動

聞き手が何を見ればよいかを残す。

content PN-02
Split Text / Evidence

左に主張、右に証拠や図解を置く

主張

テキスト側は1つの読み筋に絞る。右側は図、表、スクリーンショット、引用などを置く。

証拠

目的別フォーマットでは、この枠にブランド色や画像処理を追加する。

After
