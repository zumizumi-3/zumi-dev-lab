# Kikai Bold Depth Color Palette

## Fixed Palette

| Role | Hex | Rule |
| --- | --- | --- |
| Corporate primary | `#FC754A` | 左バー、タイトル下線、番号、重要語、主要カードの強調に使う。基準色。 |
| Corporate soft | `#FEF8F6` | Featureカード、タグ、内側カード、薄い面差に使う。背景全面には使わない。 |
| Text | `#343230` | タイトル、本文、カード見出しの基本色。黒ではなく濃いグレーで統一する。 |
| Page background | `#FFFFFF` | 全スライド背景。薄色ベタ面やグラデ背景は使わない。 |
| One-point blue | `#6697EA` | 比較の2項目目、対比、注意整理など、意味がある場合だけ使う。 |
| One-point blue soft | `#F4F8FD` | Blueカードの薄い背景。多用しない。 |
| One-point green | `#69B086` | 成果、完了、再現性、3項目目の意味づけに限定する。 |
| One-point green soft | `#F5FAF8` | Greenカードの薄い背景。多用しない。 |

## Usage Rules

- 主役は白背景、濃いグレー本文、`#FC754A` のオレンジ。赤、ボルドー、ゴールド寄りの見え方へずらさない。
- 立体感は色数ではなく、カード自体の3pt罫線、明確な面差、カード影、単色SVG、意味のある生成画像で作る。
- 多重カードでは外側を白、内側を `#FEF8F6` または意味のある薄青/薄緑にし、同一背景の入れ子を避ける。
- カード背景にグラデーションは使わない。カードは単色背景、影、罫線、余白で階層を作る。
- カード内カードは外側と同じ色系統にそろえる。オレンジ外枠なら内側も薄オレンジ、青外枠なら内側も薄青、緑外枠なら内側も薄緑にする。
- カード枠線は3ptに統一する。左だけ太いオレンジラインをオブジェクトや画像に入れない。
- カード内の文字・アイコン・画像には十分な内側余白を取り、カードや装飾画像を文字に重ねない。
- 画像・SVG・カード内オブジェクト自体に枠や影は付けない。枠と影はカード側だけに持たせ、二重枠や二重影を避ける。
- ワンポイントカラーは比較軸が必要なページに限定する。単に派手にするためには使わない。
